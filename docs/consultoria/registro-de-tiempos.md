# Registro de tiempos (una semana)

> Lo rellena quien hace la tarea, con el cronómetro del móvil, **en el momento**. No de memoria.
> Una fila por cada vez que ocurre. Si una semana es atípica, se anota y se repite.

| Fecha | Tarea | Canal | Minutos | ¿Hubo que preguntar algo al cliente? | Notas |
|---|---|---|--:|---|---|
| | | | | | |

## Cómo se usa

- **Tarea:** una de las 5 del cuestionario (por ejemplo «apuntar un pedido que llegó por WhatsApp»).
- **Minutos:** desde que llega hasta que queda hecho del todo, incluidas las preguntas de ida y vuelta.
- Al final de la semana: **media de minutos por tarea** y **cuántas veces ocurrió**.

## Mismo registro, después

Cuando la tarea esté automatizada, se repite la medición con el mismo método. Lo que se compara
es **minutos de trabajo humano por operación**, no minutos del cliente rellenando un formulario.
